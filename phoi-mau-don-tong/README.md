# Bài thực hành: Phối màu đơn tông

Bài làm theo yêu cầu **[Thực hành] Sử dụng màu sắc trong trang web**.

## Đã hoàn thành

- Màu chủ đạo: `#00ADEE`.
- Nền trang: `#00BFF2`.
- ON SALE/PREVIEW: `#00ADEE`.
- Nền phần nội dung: `#8DD7F7`.
- Footer: `#C6E9FA`.
- Chữ chính: `#000000`.
- Có thêm bảng màu đơn tông thứ hai (màu tím) cho Bước 8.
- Giao diện responsive, có thể mở trực tiếp bằng trình duyệt.

## File

- `index.html`: phiên bản xanh theo yêu cầu chính.
- `theme-purple.html`: phiên bản màu tím cho Bước 8.
- `styles.css`: CSS dùng chung.

## Chạy bài

Mở `index.html` bằng Chrome/Edge/Firefox.

Hoặc chạy:

```bash
python -m http.server 5500
```

Sau đó truy cập `http://localhost:5500/phoi-mau-don-tong/`.
