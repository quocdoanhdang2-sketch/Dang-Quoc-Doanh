# Landing Page CodeGym Career — Material Design

## Mục tiêu
Bài thực hành xây dựng lại Landing Page CodeGym Career theo phong cách Material Design bằng Bootstrap 4 + MDBootstrap.

## Nội dung nguồn
Trang tham khảo:
- https://codegym.vn/codegym-career/

Bài làm chỉ sử dụng các **ý chính và cấu trúc nội dung** như Coding Bootcamp, học thực chiến, lộ trình, dự án, khóa học và hỗ trợ nghề nghiệp. Giao diện được thiết kế lại hoàn toàn theo Material Design.

## Thành phần đã sử dụng
- Navbar responsive, fixed-top.
- Hero section dạng Material.
- Card + Grid System.
- Timeline lộ trình.
- Course cards.
- Carousel cho phần Career Service.
- CTA + form tư vấn.
- Material buttons, shadows và hover effects.
- Footer.
- Nút Back to Top.
- Responsive desktop / tablet / mobile.

## Công nghệ
- HTML5
- CSS3
- JavaScript
- Bootstrap 4.5
- MDBootstrap 4.19
- Font Awesome
- Google Fonts Roboto

## File
- `index.html`: Landing Page chính.
- `style.css`: CSS tùy chỉnh.
- `script.js`: hiệu ứng navbar, back-to-top và validation form.

## Chạy bài
Mở trực tiếp:
```powershell
start .\index.html
```

Hoặc dùng local server:
```powershell
python -m http.server 5500
```

Sau đó truy cập:
`http://localhost:5500`

## Kiểm tra responsive
Trong Chrome:
1. Nhấn `F12`.
2. Nhấn `Ctrl + Shift + M`.
3. Chọn kích thước điện thoại/tablet.
4. Kiểm tra Navbar, Hero, Card, Timeline, CTA và Footer.
